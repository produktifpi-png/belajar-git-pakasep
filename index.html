Fase 2: Persiapan dan Provisioning Server

Beri tanda centang pada kotak setelah Anda berhasil menyelesaikan setiap tahapan di konsol AWS[cite: 6]:

  • ☐ Mengaktifkan akun AWS dan login ke Management Console[cite: 6].
  • ☐ Memilih Region AWS terdekat (misal: ap-southeast-1 / Singapore)[cite: 6].
  • ☐ Memilih Amazon Machine Image (AMI), misalnya Ubuntu 22.04 LTS[cite: 6].
  • ☐ Memilih Instance Type dalam batas Free Tier (misal: t2.micro / t3.micro)[cite: 6].
PENTING: Manajemen Key Pair
Saat melakukan provisioning, AWS akan meminta Anda membuat Key Pair. File berakhiran .pem atau .ppk ini adalah "kunci rumah" server Anda. Simpan file ini di tempat yang aman. Jika hilang, Anda akan kehilangan akses ke dalam server[cite: 6].
